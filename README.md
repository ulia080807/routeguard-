# RouteGuard — MVP

Кликабельный прототип для координатора клиники: добавляет медицинское заключение и получает ближайший допустимый следующий шаг.

> ⚠️ **DEMO.** Все данные вымышлены. Реальные медицинские документы не загружаются. Это визуальный прототип, а не рабочая медицинская система.

## 📋 Пользовательский сценарий

**Роль:** Координатор клиники
**Цель:** Оформить следующий шаг маршрута пациента по заключению и отследить его выполнение

### Основной сценарий (Happy Path)

1. Координатор открывает сайт и входит как **координатор** (без пароля, DEMO-режим).
2. На главной странице «Маршруты» видит таблицу пациентов со статусами и причинами.
3. Нажимает **«+ Добавить заключение»**.
4. Выбирает DEMO-пациента, вставляет текст заключения (или выбирает готовый из списка).
5. Нажимает **«Извлечь рекомендацию»** — система показывает извлечённые поля и фрагмент-основание.
6. Система применяет правило и переводит маршрут в статус **«Требуется действие»**.
7. Координатор открывает **карточку маршрута**, видит доступные слоты.
8. Подтверждает слот → статус меняется на **«Запланировано»**.
9. Через кнопки демо-событий («Этап выполнен» / «Отмена» / «Неявка») маршрут либо **закрывается**, либо **возвращается в очередь** с причиной.

### Альтернативные сценарии

- **Нет слота:** маршрут → статус «Требуется действие», причина «Нет слота», создаётся задача ожидания.
- **Отмена / неявка:** маршрут повторно открывается с причиной и предложением новой записи.
- **Неясное заключение:** система показывает «Требуется уточнение», ничего не выдумывает.

## 🗺️ Экраны

| Раздел | Что делает |
|---|---|
| Вход | Выбор роли: координатор / администратор |
| Маршруты | Таблица пациентов, фильтры, счётчики |
| Новое заключение | Ввод текста + «извлечение» ИИ (заглушка) |
| Карточка маршрута | Этапы, причина, слоты, история, демо-события |
| Расписание | Список слотов (просмотр) |
| Аналитика | Счётчики из localStorage |
| Настройки | Только для администратора |

## 🚀 Как развернуть на GitHub Pages

1. Создай репозиторий `routeguard-` на GitHub.
2. Загрузи все файлы (Add file → Create new file).
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → Save.
4. Через 1–2 минуты ссылка появится на этой же странице.

## 📡 Описание API (для будущей серверной версии)

| Метод | Эндпоинт | Назначение |
|---|---|---|
| POST | `/api/login` | Авторизация сотрудника |
| GET | `/api/routes` | Список маршрутов с фильтрами |
| GET | `/api/routes/{id}` | Карточка маршрута |
| POST | `/api/reports` | Добавить заключение |
| POST | `/api/reports/{id}/extract` | Извлечь данные через ИИ |
| GET | `/api/slots` | Доступные слоты |
| POST | `/api/appointments` | Создать запись |
| POST | `/api/events` | Событие: отмена / неявка / выполнение |
| GET | `/api/analytics` | Счётчики состояний |
